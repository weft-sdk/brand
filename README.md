## Logo

The mark is a weave: two warp threads crossed by two weft threads, which is where the name comes from.

| File | Use it for |
| --- | --- |
| [`logo/weft-logo.svg`](logo/weft-logo.svg) | Everything that can show a vector: websites, docs, READMEs, slides |
| [`logo/weft-avatar-500.png`](logo/weft-avatar-500.png) | Profile pictures (GitHub, npm, social accounts), square with a solid background |
| [`social/social-preview.png`](social/social-preview.png) | The GitHub social preview, 1280 × 640, shown when a repository link is shared |

The social preview is rendered from [`source/social-preview.html`](source/social-preview.html). Edit the HTML and render it at 1280 × 640 to change it.

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#111111` | Backgrounds, the logo's tile |
| Paper | `#ececea` | Text on ink, the logo's light thread |
| Stone | `#a2a2a0` | Secondary text, the logo's warp threads |
| Weft blue | `#7d92ff` | Accents, links, the logo's blue thread |

## Rules

- **Keep the tile.** The logo sits on its dark rounded square. Do not recolour the threads or put it on a busy background.
- **Space.** Leave a margin of at least a quarter of the logo's width on every side.
- **Size.** Do not show it smaller than 16 px.
- **Name.** Write **Weft** in prose, `weft` in code, commands and file names (`weft.yaml`, `.weft`).
